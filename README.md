# Visualização de Dados com Python

Este repositório contém projetos e exercícios práticos focados em **Visualização de Dados**, uma habilidade essencial para qualquer profissional de **Ciência de Dados**. O conteúdo foi desenvolvido como parte da formação técnica no **SENAI de Informática de São Caetano do Sul**.

## 📊 Tecnologias e Bibliotecas

O projeto utiliza o ecossistema de análise de dados do Python:

| Biblioteca | Aplicação |
| :--- | :--- |
| **Matplotlib** | Criação de gráficos estáticos e customizados |
| **Seaborn** | Visualização estatística e estilizada de dados |
| **Pandas** | Manipulação e limpeza da base de dados para visualização |
| **Python 3** | Linguagem base para o processamento de dados |

## 🛠️ Funcionalidades e Aprendizados

A ferramenta permite ao usuário criar visualizações informativas para análise exploratória:

*   **Gráficos de Distribuição:** Histogramas, boxplots e gráficos de densidade.
*   **Gráficos de Relacionamento:** Gráficos de dispersão e correlação.
*   **Gráficos de Comparação:** Gráficos de barras, linhas e pizza.

## 🎓 Contexto Acadêmico

Este repositório é um pilar da formação em **Ciência de Dados (SENAI)**, demonstrando proficiência técnica na biblioteca mais utilizada no mercado para visualização de dados.
